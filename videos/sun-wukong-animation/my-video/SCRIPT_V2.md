# 孫悟空三借芭蕉扇 - 三段式獨立動畫腳本

> 為了達到最佳教學效果，將三個片段獨立渲染並標記為 p03, p05, p07。

## 片段 1: 芭蕉扇機制 (p03)
- 旁白：芭蕉扇威力無窮！一搧熄火，二搧生風，三搧下雨，竟然能把孫悟空一搧吹飛八萬四千里遠！
- 視覺：扇子變大 -> 風流線條 -> 火焰熄滅 -> 悟空飛出。

## 片段 2: 假扇子危機 (p05)
- 旁白：糟了！這把竟然是假芭蕉扇，一搧火勢更猛烈，再搧火焰騰起百倍，越搧火燒得越高千丈！
- 視覺：悟空搧扇 -> 火焰變白熱 -> 火焰圖示放大 -> 悟空冒汗。

## 片段 3: 智鬥騙扇 (p07)
- 旁白：牛魔王變作八戒模樣，利用悟空得勝後的驕傲與大意，輕而易舉就把寶扇騙了回去，真是以其人之道還治其人之身！
- 視覺：牛魔王疊影變八戒 -> 悟空卸下防備 -> 牛魔王取扇離去。
